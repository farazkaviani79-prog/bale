# راهنمای عملیات (پیش از انتشار)

> این راهنما یک چک‌لیست است؛ تا وقتی CI سبز نشده و اتصال بله با مستندات رسمی تأیید نشده، **انتشار برای مشتری واقعی ممنوع** است.

## متغیرهای حساس (هرگز در Git نگذارید)
`JWT_SECRET`، `APP_ENCRYPTION_KEY` (۳۲ بایت base64؛ گم شدنش یعنی توکن‌های ربات قابل بازیابی نیستند → نسخهٔ امن جداگانه نگه دارید)، رمزهای `botshop_app` / `botshop_system` / مالک دیتابیس، `SEED_ADMIN_PASSWORD`.
در Production: `NODE_ENV=production`، `BALE_MODE=http` (فقط پس از تأیید مستندات)، `NEXT_PUBLIC_MINIAPP_DEV=false`، **بدون** `THROTTLE_MULTIPLIER`.

## پشتیبان‌گیری
- روزانه: `bash scripts/backup.sh` (cron). نگهداری ۱۴ روز (`BACKUP_KEEP_DAYS`). فایل را به مکان امن بیرون از سرور منتقل و رمز کنید (`BACKUP_GPG_RECIPIENT`).
- پوشهٔ `UPLOAD_DIR` (تصاویر) را جداگانه پشتیبان بگیرید.
- **بازیابی را حداقل یک‌بار پیش از انتشار تمرین کنید:** `RESTORE_DATABASE_URL=... bash scripts/restore.sh <dump>` روی دیتابیس خالی، سپس `scripts/db-verify.sh`.

## مانیتورینگ
- `GET /health` (DB + Redis) را با یک سرویس Uptime (مثلاً UptimeRobot) هر ۱ دقیقه بررسی کنید.
- `GET /admin/ops` (فقط مدیر کل): صف‌ها، وب‌هوک/پیام‌های شکست‌خورده، `staleReservations` (اگر > ۰ باشد کار انقضا متوقف است)، شمارندهٔ خطای ۵xx. مقدار `healthy=false` یعنی نیاز به بررسی.
- لاگ‌ها JSON تک‌خطی با `x-request-id` هستند؛ Query/Header/Body ثبت نمی‌شود.

## اشتراک پلتفرم
فروشنده «درخواست تمدید» می‌زند → صورتحساب OPEN → پس از پرداخت (کارت‌به‌کارت یا روش دلخواه شما) مدیر کل `POST /admin/invoices/:id/mark-paid` را می‌زند. این پول حق‌اشتراک شماست، نه وجه مشتریان فروشگاه‌ها.

## پیش از اولین مشتری واقعی
1. CI سبز (هر دو Job).
2. تأیید مستندات بله + مالکیت وجه (`docs/decisions/0001-bale-payments.md`) و فعال‌سازی `BaleHttpAdapter` با تست.
3. HTTPS + دامنه، پشتیبان‌گیری و تمرین بازیابی، مانیتورینگ Uptime.
4. بازبینی قوانین حقوقی/مالیاتی و شرایط استفاده (خارج از حیطهٔ این کد).
